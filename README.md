# E-Commerce Sales Performance & Consumer Behavior Analysis

## 🎯 Project Overview
This project provides a comprehensive data-driven evaluation of sales operations, customer spending habits, and revenue drivers for an online retail e-commerce platform. Built entirely using Python, this portfolio project transforms raw transactional data into executive-level business insights.

## 📊 Core Tasks Completed
* **Exploratory Data Analysis (EDA):** Cleaned structural data, handled duplicate records, verified data integrity, and evaluated high-level statistics.
* **Data Visualization:** Engineered analytical charts mapping revenue allocation across product categories, demographic spending power, and market volume distribution.

## 🛠️ Tech Stack & Libraries Used
* **Language:** Python
* **Environment:** Google Colab / Jupyter Notebook
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn

## 💡 Key Business Insights Extracted
1. **Revenue Stream Leader:** The **Electronics** division serves as the primary driver for this retail platform, commanding a massive **48.1%** of the total aggregate spend across all categories.
2. **Geographical Distribution:** Market demand remains exceptionally balanced, with the top leading regions holding stable, near-equal shares of market volume.
3. **Demographic Buying Power:** The consumer scatter analysis clearly reveals that the highest-spending customers (transactions scaling between \$25,000 and \$35,000) are heavily concentrated within the younger-to-middle-aged brackets, with spending volumes steadily decreasing as age increases.
